# 흰토끼 (가제) — 게임 기획서

- 문서 버전: v0.3
- 작성일: 2026-11-22
- 엔진: Godot 4.7 / 기준 해상도 480×270 / PC 전용

### v0.3 변경 사항

- 엔딩 크레딧 변경: 에필로그 뒤 크레딧 곡과 함께 **오른쪽은 크레딧, 왼쪽은 후일담 일러스트**. 도와준 동물과 쫓아오던 동물들의 그해 봄. 따로 있던 쿠키 영상은 여기로 합침 ([10.3](#103-엔딩-크레딧과-후일담-일러스트))
- 추락 처리 확정: **온기 -1 후 그 자리에서 복귀** ([4.4](#44-온기-게이지-체력))
- 곡 구성 변경: 에피소드 1~5는 **전반곡 + 후반곡 2곡**. 사이에 중간 장면과 추격 카운트인. 에피소드 6은 재회 장면까지 **이어진 긴 1곡** ([2.2](#22-에피소드-한-판의-구성), [12.2](#122-곡-목록))
- 플랫폼 확정: **PC 전용**
- 곡은 추후 직접 작업. 초기 개발용 **임시 박자 음원**과 생성 스크립트 추가 ([14.5](#145-임시-박자-음원))

### v0.2 변경 사항

- 스테이지 시작 흐름 변경: 솜이 걸어 들어와 멈춤 → 자연 소리 속 대기(그루밍, 두리번) → 아무 키 → 카운트인 → 노래와 함께 출발
- 흰토끼와 검은토끼는 **대사 없음**. 내레이션 자막도 쓰지 않고 장면과 몸짓만으로 전달. 도와주는 동물(NPC)만 말한다
- 헤어지는 계기 변경: 검은토끼의 희생 → **폭풍 밤의 비탈 붕괴와 불어난 물살**에 휘말린 사고
- 두 토끼는 영웅이 아닌 **작고 약한 존재**. 아무것도 이기지 못하고 숨고, 달리고, 도움을 받는다
- **판타지 요소 전부 제거**. 괴물은 평범한 동물이며, 토끼의 눈에 거대하고 무섭게 보일 뿐이다
- 여정 변경: 흰 산을 오르는 여정 → **강을 따라 하류로 내려가는 여정** (늦가을 → 첫눈)

## 1. 개요

### 1.1 한 줄 소개

> 폭풍에 휩쓸려 헤어진 단짝 검은토끼를 찾아, 작고 겁 많은 흰토끼가 음악의 박자에 맞춰 강을 따라 달린다.

### 1.2 디자인 기둥

| 기둥 | 설명 |
|---|---|
| **리듬에 맞춰 달린다** | 장애물, 동물의 공격, 쫓아오는 짐승의 움직임이 모두 BGM 박자에 맞춰 나온다. 음악을 들으면 피할 타이밍이 들린다. |
| **토끼의 눈으로 본 세상** | 개, 멧돼지, 여우 같은 평범한 동물이 작은 토끼의 눈높이에서는 괴물처럼 거대하다. 이길 수 없으니 피하고 숨고 달린다. |
| **말없이 전하는 이야기** | 두 토끼는 말하지 않는다. 귀, 코, 몸짓, 장면만으로 감정과 이야기를 전한다. |

### 1.3 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 리듬 액션 러너 (자동 달리기 횡스크롤) |
| 그래픽 | 2D 도트(픽셀 아트), 시네마틱한 장면 연출 |
| 전투 | 없음. 점프·이중점프·대쉬·숙이기·구르기로 피하기만 한다 |
| 구성 | 프롤로그 영상 → 튜토리얼 → 에피소드 6개 → 엔딩 → 엔딩 크레딧 |
| 곡 구성 | 에피소드 1~5는 전반곡 + 후반곡(추격) 2곡, 에피소드 6은 이어진 긴 1곡 |
| 에피소드 길이 | 곡 약 3분~3분 30초 (전반곡 약 2분 + 후반곡 약 1분 20초). 장면 포함 6~7분 |
| 총 플레이 시간 | 첫 클리어 약 1.5~2시간 (재도전 포함) |
| 플랫폼 | **PC 전용** (키보드 / 게임패드) |

### 1.4 참고

- **연출·도트 질감**: 산나비 — 도트 그래픽의 시네마틱한 연출, 장면과 플레이가 끊김 없이 이어지는 방식. (전투·갈고리 액션은 가져오지 않는다.)
- **리듬 러너 구조**: 음악에 맞춰 배치된 장애물을 자동 달리기로 돌파하는 장르 문법.
- **예고 → 실행 패턴**: 리듬게임의 콜 앤 리스폰스. 동물이 박자에 맞춰 신호를 보내고, 정해진 박자에 덮친다.

## 2. 게임 흐름

### 2.1 전체 흐름

```
타이틀
 └ 새 게임
    └ 프롤로그 영상 (약 2분, 대사 없음, 길게 눌러 스킵)
       └ 튜토리얼 '비 그친 아침' (음악 없음, 약 2분)
          └ 에피소드 1 쓰러진 숲        (전반곡 + 후반곡)
          └ 에피소드 2 불어난 강        (전반곡 + 후반곡)
          └ 에피소드 3 추수 끝난 농장   (전반곡 + 후반곡)
          └ 에피소드 4 큰길 밑 굴       (전반곡 + 후반곡)
          └ 에피소드 5 서리 내린 갈대밭 (전반곡 + 후반곡)
          └ 에피소드 6 첫눈             (이어진 긴 1곡)
             └ 엔딩 영상 → 에필로그 '봄' → 엔딩 크레딧 (후일담 일러스트)
```

- 클리어한 에피소드는 **여정 지도**에서 다시 할 수 있다 (랭크 갱신, 수집품 회수).
- 이어하기는 마지막으로 도달한 에피소드의 등장 장면부터.

### 2.2 에피소드 한 판의 구성

| 순서 | 단계 | 내용 |
|---|---|---|
| 1 | **제목 카드** | 여정 지도에서 다음 장소로 발자국이 이어지고, 에피소드 제목이 뜬다 |
| 2 | **등장** | 새 맵. 솜이 화면 왼쪽에서 천천히 깡총깡총 걸어 들어와 화면 가운데쯤에 멈춘다 |
| 3 | **만남** (있는 경우) | 그 장소의 동물이 나타나 말을 건다. 솜은 말 없이 몸짓으로 반응한다. 대화는 키로 넘긴다 |
| 4 | **대기** | 음악 없이 풍경 소리만 들린다. 솜은 그루밍하거나 주위를 둘러본다. 플레이어가 아무 키나 누를 때까지 계속 ([2.3](#23-대기-상태)) |
| 5 | **카운트인** | 아무 키 입력 → 솜이 박자에 맞춰 뒷발로 땅을 구르며 박자를 센다 ([2.4](#24-카운트인-출발-신호)) |
| 6 | **전반 (전반곡)** | 카운트인이 끝나는 순간 전반곡이 시작되고 솜이 앞으로 달려 나간다. 길 위의 장애물과 방해하는 동물. 약 2분 |
| 7 | **중간 장면** | 전반곡이 잦아들며 끝나고, 마지막 박에 솜이 멈춰 선다. 음악 없이 풍경 소리 속에서 쫓아오는 것이 모습을 드러낸다. 조작 없음, 5~15초 |
| 8 | **추격 카운트인** | 쫓아오는 것의 소리로 1마디를 센다 ([2.4](#24-카운트인-출발-신호)) |
| 9 | **후반 (후반곡)** | 후반곡이 시작되고 추격이 벌어진다. 약 1분 20초. 작은 몸을 이용한 탈출로 끝난다 |
| 10 | **도착 장면** | 대사 없는 짧은 장면. 먹의 흔적을 발견하거나 다음 장소를 바라본다 |
| 11 | **결과 화면** | 전반·후반 합산 랭크, 정확도, 수집품 |

> - 튜토리얼은 음악이 없으므로 카운트인 없이, 아무 키를 누르면 바로 달려 나간다.
> - 에피소드 6은 전반·후반으로 나누지 않고 재회 장면까지 **이어진 긴 1곡**이다. 중간 장면과 추격 카운트인이 없다 ([에피소드 6](#에피소드-6-첫눈-최종)).
> - 중간 장면은 처음 한 번만 보여 준다. 후반에서 실패해 다시 할 때는 건너뛴다.

### 2.3 대기 상태

노래가 시작되기 전, 플레이어가 그 장소의 분위기에 잠시 머무는 시간이다. 대기 중에는 음악을 틀지 않는다. 그래야 카운트인 뒤 노래가 터질 때의 대비가 커진다.

**들리는 소리**: 풍경에 맞는 자연 소리 (에피소드별 표의 '대기 소리' 참고). 예) 숲은 새소리와 물방울, 강은 물살과 오리 소리, 갈대밭은 바람과 갈대 쓸리는 소리.

**솜의 대기 행동** — 3~6초 간격으로 무작위 재생:

| 행동 | 모습 |
|---|---|
| 세수 | 앞발에 침을 묻혀 얼굴을 닦는다 |
| 귀 손질 | 귀를 앞발로 끌어내려 핥는다 (접힌 한쪽 귀) |
| 망보기 | 뒷발로 서서 고개를 들고 두리번거린다 |
| 냄새 맡기 | 코를 씰룩이며 땅 냄새를 맡는다 |
| 귀 돌리기 | 소리 나는 쪽으로 귀를 한쪽씩 돌린다 (풍경 소리와 연동) |
| 몸 털기 | 몸을 부르르 털어 물기나 눈을 털어 낸다 (젖거나 눈 오는 장면) |
| 풀 뜯기 | 발밑의 풀을 오물오물 먹는다 |

- 30초 넘게 입력이 없으면 식빵 자세로 엎드려 꾸벅꾸벅 존다. 키를 누르면 화들짝 일어난다.
- 화면 아래에 "아무 키나 누르세요"를 희미하게 띄운다.
- 대화를 넘기던 키가 그대로 출발로 이어지지 않도록, 대화가 끝난 뒤 1초 동안은 입력을 받지 않는다.

### 2.4 카운트인 (출발 신호)

**카운트인이란?** 음악을 시작하기 전에 박자를 미리 세어 주는 것. 밴드 드러머가 연주 전에 스틱을 딱딱 치며 "원, 투, 쓰리, 포" 하는 것과 같다.

**왜 필요한가?** 이 게임은 BGM 첫 박부터 장애물이 박자에 맞춰 나온다. 음악이 갑자기 시작되면 플레이어가 박자를 잡을 틈이 없다. 그래서 출발 직전에 그 곡의 빠르기를 미리 몸으로 느끼게 해 준다.

**게임에서는 이렇게 보인다.** 화면에 "3, 2, 1" 숫자를 띄우는 대신, 솜의 동작으로 박자를 센다.

| 박 | 화면 | 소리 |
|---|---|---|
| (입력) | 솜이 귀를 쫑긋 세우고 앞을 본다 | - |
| 1박 | 솜이 뒷발로 땅을 구른다 | 쿵 |
| 2박 | 한 번 더 구른다 | 쿵 |
| 3박 | 한 번 더 구른다 | 쿵 |
| 4박 | 귀를 세운 채 잠깐 기다린다 | (조용함) |
| 다음 박 | 노래 시작, 솜이 달려 나감 | ♪ |

- 4/4박자 곡에서 1마디는 4박이므로, 카운트인은 딱 1마디 길이다.
- '쿵' 사이 간격은 그 곡의 BPM을 따른다. 빠른 곡일수록 '쿵'도 빠르다.
- 체크포인트에서 다시 시작할 때, 일시정지를 풀 때도 그 곡의 카운트인을 쓴다 (이때는 대기 없이 바로). 전반곡은 솜의 카운트인, 후반곡은 추격 카운트인.

**추격 카운트인** — 후반곡 앞에서는 솜이 아니라 **쫓아오는 것의 소리**가 박자를 센다. 후반곡의 BPM을 따른다.

| 에피소드 | 1~3박 | 4박 (가장 큰 소리) |
|---|---|---|
| 1 | 멧돼지가 앞발로 땅을 긁는 소리 | 콧김 "푸흥!" — 돌진 시작 |
| 2 | 상류의 우르릉 | 쌓였던 나뭇가지 더미가 터지는 "콰앙" |
| 3 | 사슬이 팽팽하게 당겨지는 "철컥" | 낡은 사슬이 끊어지는 "뚝!" |
| 4 | 옆 관에서 "찍" | 족제비가 관에서 튀어나오는 "철벅" |
| 5 | 갈대를 헤치며 다가오는 "사각" | 여우가 갈대 위로 높이 뛰어오르는 소리 |

- 솜의 카운트인은 4박째가 비어 있고, 추격 카운트인은 4박째가 가장 크다. 솜이 기다리는 대답 대신 위협이 온다.
- 4박째 소리와 동시에 솜이 귀를 등에 붙이고 돌아서 달리기 시작한다.

**이야기 속 의미** — 대사 없이 장면으로만 전달한다.

- 실제 토끼는 위험을 알리거나 신호를 보낼 때 뒷발로 땅을 '쿵' 구른다. 이 게임에서는 그것을 솜과 먹의 신호로 쓴다.
- 프롤로그에서 둘은 숨바꼭질을 한다. 덤불 뒤에 숨은 먹이 쿵쿵쿵 구르면, 솜이 그 소리를 따라가 먹을 찾아낸다. **쿵쿵쿵 = "나 여기 있어"**라는 것을 플레이어는 이 장면으로 알게 된다.
- 폭풍 다음 날 아침, 혼자 남은 솜이 쿵쿵쿵 구르고 귀를 세워 기다리지만 대답이 없다.
- 그래서 스테이지를 시작할 때마다 솜은 쿵쿵쿵으로 먹을 부르고, **4박째에 대답을 기다린다.** 대답은 없고, 솜은 다시 달려 나간다.
- 마지막 에피소드(Ep6)의 카운트인에서 처음으로 그 빈 4박째에 멀리서 희미한 '쿵'이 들린다. 먹의 대답이다. 게임 내내 비어 있던 박자가 채워지는 순간이다.

## 3. 조작

### 3.1 키 배치 (기본값, 변경 가능)

| 동작 | 키보드 | 게임패드 | 리듬 노트 성격 |
|---|---|---|---|
| 점프 | `Space` 또는 `↑` | A | 단타 |
| 이중점프 | 공중에서 점프 한 번 더 | A | 2연타 |
| 대쉬 | `Shift` 또는 `→` | X 또는 RB | 단타 (주로 강박) |
| 숙이기 | `S` 또는 `↓` **길게** | B 길게 / 십자키 ↓ | 롱노트 |
| 구르기 | `S` 또는 `↓` **짧게** | B 짧게 | 단타 |
| 일시정지 | `Esc` | Start | - |

> **숙이기와 구르기는 같은 키**를 쓴다. 누르는 순간 구르기가 시작되고, 계속 누르고 있으면 구르기가 끝난 뒤 숙인 자세가 유지된다. 리듬게임의 "단타 / 롱노트" 구분과 같아 익히기 쉽다. (별도 키 분리는 [미결정 사항](#16-미결정-사항) 참고)

### 3.2 동작 상세

동작은 실제 토끼의 움직임을 조금 과장한 정도로 연출한다. 초능력처럼 보이지 않게 한다.

| 동작 | 효과 | 주로 피하는 것 | 토끼다운 연출 |
|---|---|---|---|
| **점프** | 짧게 누르면 낮게, 길게 누르면 높게 (가변 높이) | 땅 위의 낮은 장애물, 돌진하는 동물 | 뒷발로 튀어 오르는 깡충 |
| **이중점프** | 공중에서 1회. 착지하면 다시 사용 가능 | 높은 장애물, 넓은 구덩이 | 토끼가 신날 때 공중에서 몸을 비트는 점프(빙키) |
| **대쉬** | 약 반 박자 동안 중력을 무시하고 앞으로 튀어 나감. 공중 1회. 대쉬 중에는 덤불·마른 풀더미를 뚫는다 | 넓은 구덩이(점프와 조합), 길을 막은 덤불, 추격 중 거리 벌리기 | 몸을 쭉 뻗고 뒷발로 땅을 박차는 순간 가속 |
| **숙이기** | 누르는 동안 몸을 낮춤 (충돌 높이 절반). 공중에서 누르면 **급강하** | 머리 높이 장애물, 낮은 틈, 수평으로 오는 공격 | 귀를 등에 붙이고 바닥에 납작 엎드려 기기 |
| **구르기** | 약 0.35초 구르며 그동안 **무적** | 위에서 떨어지는 것, 위에서 덮치는 동물 | 몸을 공처럼 말아 데굴 |
| **착지 구르기** | 착지 직전 0.1초 안에 구르기 입력 | 높은 곳에서 떨어질 때 휘청임 방지 + 판정 보너스 | |

### 3.3 조합 규칙

- **점프 → 대쉬**: 넓은 구덩이를 건너는 기본 조합.
- **이중점프 → 대쉬**: 가장 멀리 가는 조합. 후반 에피소드에서 사용.
- **공중 숙이기(급강하) → 구르기**: 빨리 내려앉아 바로 다음 박자에 대응.
- 숙인 상태에서 점프를 누르면 즉시 일어나며 점프한다 (빠른 연속 패턴 대응).
- 지상 대쉬는 반 박자 쿨타임.

## 4. 핵심 시스템

### 4.1 자동 달리기와 음악 동기화

**원칙: "음악이 시계다."**

- 솜의 **가로 위치는 음악 재생 시간으로 결정**한다. `x = 곡 시간 × 달리기 속도`. 프레임이 떨어져도 음악과 위치가 어긋나지 않는다.
- **세로 움직임(점프·낙하)만 물리**로 처리한다.
- 대쉬는 세계 좌표상 앞으로 가는 것이 아니라 **중력 무시 + 덤불 돌파 판정 + 화면상 전진 연출**(솜이 화면에서 몇 픽셀 앞으로 튀었다가 1박에 걸쳐 제자리로 돌아옴, 흙먼지·속도선)이다. 그래서 음악 싱크가 깨지지 않는다.
- 달리기 속도는 **1박당 가로 칸 수**로 정한다. 예) 1박 = 4타일(16px 타일 → 64px). 104 BPM이면 초당 약 111px.
- 레벨은 **박자 격자** 위에서 만든다. 에디터에 1박/1마디마다 세로선이 보이고, 장애물은 "입력해야 하는 박자" 위치에 놓는다.
- 곡 안에서 템포나 박자가 바뀌는 곡(Ep5 전반곡의 7/8 구간, Ep6의 138 → 152 BPM)은 구간별 BPM·박자표(템포 맵)를 쓴다. 나머지 곡은 BPM 하나로 끝난다.
- 전반곡과 후반곡은 한 맵에 이어 붙인다. 후반곡에서는 전반이 끝난 지점부터 다시 `x = 후반 시작 x + 후반곡 시간 × 속도`로 센다.

### 4.2 장애물 배치 원칙

1. **입력 타이밍은 항상 박자 위.** 기본은 4분·8분음표, 어려운 구간만 16분음표.
2. **악기와 동작을 짝지운다** (권장 규칙):

   | 동작 | 짝이 되는 소리 |
   |---|---|
   | 점프 | 킥 드럼, 베이스 |
   | 이중점프 | 하이햇 2연타 |
   | 구르기 | 스네어 |
   | 대쉬 | 크래시 심벌, 강박 악센트 |
   | 숙이기 | 지속음 (현악 롱톤, 패드) — 소리 길이 = 숙이는 길이 |

3. **새 기믹은 3단계로 소개**한다: ① 안전하게 단독 등장 → ② 반복 → ③ 다른 기믹과 조합.
4. **곡의 구조 = 레벨의 구조**:
   - 전반곡: 인트로(쉬움) → 벌스(새 기믹) → 코러스(밀도 ↑) → 벌스 2(방해하는 동물) → 엔딩(잦아들며 멈춤)
   - 후반곡: 인트로(추격 시작, 장애물 적게) → 추격 1 → 추격 2(지형 변화) → 탈출(곡의 마지막 강박)
5. **숨 고르기**: 16마디마다 1~2마디는 장애물 없이 배경과 연출을 보여 준다.

### 4.3 판정과 피드백

- 통과 여부는 **충돌**로 정한다. 부딪히지 않으면 통과.
- 동시에 장애물마다 설계된 "목표 박자"와 실제 입력 시간을 비교해 **판정 등급**을 매긴다.

| 등급 | 오차 | 연출 |
|---|---|---|
| 완벽 | ±50ms | 흙·물·눈이 시원하게 튐 + 곡에 차임 소리가 겹침 |
| 좋음 | ±100ms | 작은 흙먼지 |
| 통과 | 그 밖의 성공 | 없음 |
| 피격 | 충돌 | 화면 흔들림, 솜이 휘청이며 귀가 눕혀짐, 온기 -1 |

- **리듬 콤보**: 완벽이 이어지면 곡에 레이어(코러스·화음)가 하나씩 더해진다. 잘 달릴수록 음악이 풍성해진다.
- 충돌 박스는 그림보다 조금 작게 (관대한 판정).

### 4.4 온기 게이지 (체력)

작은 토끼는 혼자 있으면 금방 몸이 식는다. 체력은 솜의 **체온**이다.

- 화면 왼쪽 위, 작은 아이콘 5칸 (어려움 3칸).
- 피격 시 -1, 1박 동안 무적(깜박임).
- **추락 = 온기 -1 후 복귀.** 구덩이나 물에 빠져도 체크포인트로 돌아가지 않고, 음악도 멈추지 않는다.
  1. 빠지는 순간 물보라나 흙탕이 튀고, 솜이 허우적댄다. 온기 -1.
  2. 솜의 가로 위치는 음악을 따라 계속 앞으로 간다. 솜이 구덩이 건너편 가장자리에 닿으면, 앞발로 가장자리에 매달려 기어오르는 모습으로 복귀한다.
  3. 복귀 후 2박 동안 무적(깜박임).
  - 레벨 규칙: 구덩이 폭은 최대 3박. 건너편 복귀 지점에서 1박 안에는 장애물을 두지 않는다.
  - 추격 중 추락은 실수로 쳐서 거리가 한 단계 가까워진다. 온기가 1칸 남았을 때 추락하면 쓰러진다.
- **풀잎**을 10개 먹으면 +1. 계절에 따라 모양이 바뀐다 (클로버 → 마른 풀 → 눈 속 풀싹).
- 0이 되면 솜이 쓰러짐 → 마지막 체크포인트에서 다시 시작.
- 온기가 줄수록 솜이 몸을 떨고 입김이 짙어지며, 화면 가장자리가 차갑게 어두워지고 음악 고음역이 살짝 먹먹해진다.
- **추위 구간**: Ep5 해 질 녘 이후와 Ep6 1부(혼자 달리는 눈밭)에서는 추위 때문에 온기가 천천히 계속 줄어, 풀잎을 꾸준히 먹어야 한다. Ep6 3부에서는 먹과 함께이므로 추위로 온기가 줄지 않는다.

### 4.5 추격 구간

- **후반곡 전체가 추격이다.** 중간 장면에서 모습을 드러낸 거대한 짐승(또는 물살)이 추격 카운트인의 4박째에 덮쳐 오고, 후반곡 동안 화면 왼쪽에서 쫓아온다. 카메라가 살짝 줌아웃된다. (Ep6은 긴 곡의 3부가 추격)
- 화면 아래에 **거리 게이지** (솜 아이콘 ↔ 짐승 아이콘). 3단계: **여유 → 근접 → 위험**.
  - 위험 단계: 짐승의 주둥이와 그림자가 솜에게 닿을락말락, 거친 숨소리와 심장 박동 소리.
- 실수(피격·휘청·추락)하면 한 단계 가까워짐. **위험 단계에서 실수하면 잡힘 → 실패.**
- 완벽 4연속 또는 대쉬 돌파 성공 시 한 단계 멀어짐.
- 짐승의 행동도 박자에 맞춰, 반드시 **예고 후 실행**:

  | 짐승 행동 | 피하는 법 |
  |---|---|
  | 앞발로 땅을 내리찍기 (강박) | 점프 |
  | 주둥이로 물려고 머리를 휘두르기 (머리 높이) | 숙이기 |
  | 위에서 덮치기 | 구르기 |
  | 돌진하며 지형 부수기 | 앞 지형이 바뀜 (쓰러진 나무, 부서진 울타리 등) |

- **솜은 절대 짐승을 이기지 못한다.** 추격은 언제나 솜이 작은 몸을 이용해 빠져나가는 **탈출 연출**(좁은 틈, 가시덤불, 높은 바위 등)로 끝난다. 컷신이 아닌 인게임 스크립트로, 음악의 마지막 강박과 맞춘다.

### 4.6 동물과 예고 규칙

- 방해하는 동물은 모두 **평범한 동물**이다. 사악한 존재가 아니라 배고프거나, 놀랐거나, 자기 영역을 지키는 것뿐이다.
- 모든 동물은 덮치기 전에 **그 동물의 실제 습성**으로 박자 신호를 보낸다.

  | 동물 | 예고 (박자) | 행동 |
  |---|---|---|
  | 까마귀 | "까악, 까악" (2박) | 급강하 → 구르기 |
  | 왜가리 | 목을 S자로 접음 (2박) | 부리로 내리찍기 → 구르기 |
  | 수탉 | 날개를 퍼덕임 (2박) | 돌진 → 점프 |
  | 거위 | "꽥꽥" 하며 목을 낮춤 (2박) | 목을 뻗어 쪼기 (머리 높이) → 숙이기 |
  | 매 | 땅 위 그림자가 점점 커짐 (2박) | 낚아채기 → 구르기 |
  | 족제비 | 옆 관에서 "찍찍" (2박) | 튀어나옴 → 점프 |

- 예고 소리는 그 곡의 박자와 음계에 맞춰 다듬어, **듣기만 해도** 피할 수 있게 한다.
- 어두운 곳에서는 동물의 **눈에 빛이 반사되어 번쩍이는 것**이 예고 신호다.

### 4.7 체크포인트와 재시작

- 곡의 구간 경계(보통 16마디마다)에 체크포인트. 배경에 작은 풀숲이나 굴로 표시.
- **후반곡의 시작은 언제나 체크포인트**다. 후반에서 실패하면 전반으로 돌아가지 않는다.
- 실패 시: 0.5초 암전 → 체크포인트 1마디 앞에서 카운트인 후 음악 재개 → 온기 가득 찬 상태로 재시작.
- 일시정지 후 재개도 1마디 되감기 + 카운트인.

### 4.8 수집 요소, 점수, 랭크

| 요소 | 내용 |
|---|---|
| **풀잎** | 흔하게 배치. 점수 + 온기 회복. 주로 엇박에 배치해 리듬감을 더한다. 먹는 소리는 곡의 음계에 맞춘 짧은 차임 |
| **검은 털** | 에피소드당 3개. 위·아래 숨은 길(이중점프나 급강하로 진입)의 나뭇가지나 갈대에 걸려 있는, 떠내려가던 먹의 털. 3개 모으면 솜과 먹의 추억 **회상 장면** 해금 (갤러리) |
| **랭크** | S / A / B / C. 판정 정확도 + 피격 수 + 수집률. S는 체크포인트 재시작 없이 클리어해야 가능 |

회상 장면 목록 (모두 대사 없음, 20~30초):

| 에피소드 | 회상 제목 | 장면 |
|---|---|---|
| 1 | 첫 굴 파기 | 참나무 아래 굴을 처음 판 날. 먹이 앞발로 파고, 솜이 뒤에서 흙을 차내다 흙을 뒤집어쓴다 |
| 2 | 첫 물웅덩이 | 비 온 뒤 물웅덩이 앞에서 떠는 솜. 먹이 먼저 폴짝 건너가 돌아보고, 솜이 눈을 질끈 감고 건넌다 |
| 3 | 숨바꼭질의 시작 | 처음 숨바꼭질을 하던 날, 솜이 먹을 못 찾아 귀를 늘어뜨린다. 덤불 뒤에서 먹이 쿵쿵쿵 굴러 알려 준다. 신호가 생긴 날 |
| 4 | 접힌 귀 | 솜의 접힌 한쪽 귀를 먹이 매일 핥아 주던 모습 |
| 5 | 열나던 밤 | 솜이 앓던 밤, 먹이 한숨도 안 자고 몸을 붙여 주던 모습 |
| 6 | 작년 첫눈 | 작년 첫눈 날 눈밭에서 뛰어놀다, 솜이 눈 속에 파묻혀 안 보이자 먹이 허둥대며 찾는 모습 |

### 4.9 난이도와 접근성

| 모드 | 내용 |
|---|---|
| 이야기 | 판정 범위 넓음, 피격해도 온기 감소 없음. 스토리 감상용 |
| 보통 | 기본 |
| 어려움 | 온기 3칸, 추가 노트 패턴, 예고 연출 축소 |

- **오디오 지연 보정 (필수)**: 박자 소리에 맞춰 키를 누르는 보정 화면. 첫 실행 시 안내.
- 화면 흔들림·번쩍임 끄기, 색약 모드 (위험 표시를 색 + 모양으로).
- 연습 모드 (클리어 후): 구간 선택, 0.75배속.

### 5.1 위협과 동작의 대응 (게임의 시각 언어)

플레이어가 위협의 **모양**만 보고 동작을 바로 떠올릴 수 있도록, 이 규칙은 게임 전체에서 지킨다.

| 위협의 모양 | 동작 | 예 |
|---|---|---|
| 땅 위의 낮은 것 / 돌진해 오는 것 | 점프 | 쓰러진 나무, 돌, 돌진하는 수탉, 굴러오는 깡통 |
| 높은 것 / 넓은 틈 | 이중점프 (+대쉬) | 건초더미, 무너진 강둑, 물길 |
| 머리 높이로 오는 것 / 낮은 틈 | 숙이기 (길이만큼 유지) | 낮은 가지, 빨랫줄의 이불, 철망, 박쥐 떼, 거위의 쪼기 |
| 위에서 떨어지는 것 / 위에서 덮치는 것 | 구르기 | 솔방울, 떨어지는 흙, 까마귀·매의 급강하, 왜가리 부리 |
| 앞을 막는 덤불 | 대쉬 | 마른 덤불, 엉킨 풀더미 |

## 6. 세계관과 캐릭터

### 6.1 세계

- 판타지 요소가 없는 **현실의 시골**. 산자락의 숲에서 시작해 강을 따라 농장, 큰길 밑 배수로, 갈대밭, 넓은 들판으로 내려간다.
- 사람은 화면에 나오지 않는다. 농장의 불빛, 큰길을 지나는 차 소리처럼 흔적만 있다.
- 계절은 **늦가을 폭풍 → 첫서리 → 첫눈**으로 흐른다. 갈수록 추워지고, 혼자인 솜에게 추위는 큰 위험이 된다.
- 동물들끼리는 말이 통한다는 우화식 설정은 쓴다. 단, **솜과 먹은 말하지 않는다.**

### 6.2 주제

> **작고 약한 것들은, 서로 붙어서 겨울을 난다.**

- 솜과 먹은 영웅이 아니다. 아무것도 이기지 못한다. 숨고, 달리고, 버티고, 다른 동물들의 도움을 받는다.
- 세상의 '괴물'들은 사실 평범한 동물이다. 토끼의 눈높이에서 거대하고 무서워 보일 뿐이다. 무섭게 생긴 동물이 친절하기도 하고(늙은 고양이, 고라니), 쫓아오는 동물은 그저 배가 고플 뿐이다(여우).
- 토끼는 혼자서는 금방 식는다. 이야기는 굴 안에서 몸을 붙인 두 토끼로 시작해, 몸을 붙인 두 토끼로 끝난다.

### 6.3 표현 원칙 — 말없는 두 토끼

- 솜과 먹은 대사가 없다. 말풍선, 생각 풍선, 내레이션 자막도 쓰지 않는다.
- 모든 감정은 **실제 토끼의 몸짓**으로 표현한다.
- 도와주는 동물은 대화창으로 말한다. 솜은 귀, 고개, 코로 대답한다.

| 감정 | 몸짓 |
|---|---|
| 기쁨 | 빙키 — 공중으로 뛰어올라 몸을 비틀기 |
| 애정 | 서로 귀와 얼굴을 핥아 주기 (그루밍), 코 맞대기 |
| 두려움 | 그 자리에 얼어붙기, 귀를 등에 바짝 붙이기, 몸 떨기 |
| 슬픔·실망 | 귀가 축 늘어짐, 웅크려 고개 숙이기 |
| 호기심·희망 | 귀를 쫑긋 세우기, 코를 빠르게 씰룩이기, 뒷발로 서서 멀리 보기 |
| 경고 | 뒷발로 땅을 쿵 구르기 |
| 안심 | 옆으로 털썩 눕기 |
| 추위 | 몸을 동그랗게 말기, 털 부풀리기, 입김 |

### 6.4 두 토끼

#### 솜 — 흰토끼 (주인공)

- 작고 겁이 많고 몸이 약하다. 추위를 많이 탄다. 늘 먹의 등 뒤에 붙어 다닌다.
- **한쪽 귀가 살짝 접혀 있다.** 약하고 작은 아이라는 표시이자, 먼 장면에서도 알아볼 수 있는 특징.
- 귀가 밝아 작은 소리도 잘 듣는다 → 소리를 듣고 달리는 게임 플레이와 연결된다.
- 여정 동안 솜은 강해지지 않는다. 여전히 겁먹고, 떨고, 얼어붙는다. 그래도 **한 발씩 계속 앞으로 간다.** 그것이 솜의 성장이다.
- 게임 안에서 이름이 불리지 않는다 ('솜'은 기획용 이름). 동물들은 "하얀 꼬마"라고 부른다.

#### 먹 — 검은토끼 (친구)

- 솜보다 조금 크다. 호기심이 많아 늘 먼저 고개를 내밀지만, 역시 작은 토끼일 뿐이다.
- **가슴에 작은 흰 점**이 있다. 동물들의 목격담에서 "가슴에 흰 점 있는 까만 토끼"로 불린다.
- 게임 안에서 이름이 불리지 않는다 ('먹'은 기획용 이름).

#### 먹에게 있었던 일 (플레이어에게 직접 말하지 않는 숨은 설정)

동물들의 목격담과 흔적으로 플레이어가 조금씩 짐작하게 한다.

1. 폭풍 밤, 흙탕물에 빠져 떠내려가는 나뭇가지에 매달린다.
2. 날이 밝을 무렵 숲과 강을 지나 농장 옆을 떠내려간다 (Ep1, Ep2 목격담).
3. 큰길 밑 배수로로 빨려 들어가, 콘크리트 턱에 부딪혀 **뒷다리를 다친다** (Ep4 목격담).
4. 배수로 끝에서 갈대밭으로 겨우 기어 나온다 (Ep4 도착 장면의 발자국).
5. 갈대밭 너머 들판의 늙은 버드나무 뿌리 밑 얕은 구멍에 숨어, 나무껍질을 갉으며 버틴다 (Ep5 목격담, Ep6).

### 6.5 도와주는 동물 (NPC)

모두 평범한 동물이다. 토끼의 눈에는 크게 보인다.

| 에피소드 | 동물 | 성격 | 주는 도움 |
|---|---|---|---|
| 1 | 청설모 | 수다스럽고 덜렁댐 | 새벽에 먹이 나뭇가지에 매달려 떠내려가는 걸 봤다. 멧돼지 경고 |
| 2 | 청둥오리 엄마 (새끼 오리들과 함께) | 다정하고 걱정 많음 | 먹이 살아 있었다는 목격담. 스테이지 중 새끼 오리들이 앞서 헤엄치며 건널 길을 보여 줌 |
| 3 | 늙은 고양이 | 무뚝뚝하지만 속은 따뜻함. 이빨이 빠져 사냥을 못 함 | 떠내려온 것은 큰길 밑 굴로 들어간다. 농장 개와 여우 경고 |
| 4 | 박쥐 | 장난스럽고 말이 빠름 | 먹이 다리를 절며 굴을 빠져나갔다. 어둠 구간에서 박자마다 찍찍거려 길을 알려 줌 |
| 5 | 고라니 | 느릿하고 수줍음. 송곳니 때문에 무섭게 생겼지만 풀만 먹음 | 먹이 버드나무 쪽으로 갔다. 여우가 따라오고 있다고 경고. 추격 끝에 갈대를 헤치고 뛰어나와 여우를 놀라게 함 |
| 6 | (없음) | - | 재회는 두 토끼만의 장면으로 남긴다 |

- 늙은 고양이와 고라니는 처음 나타날 때 **무서운 조명(역광, 번쩍이는 눈)**으로 등장하고, 말을 시작하면 조명이 부드러워진다. "무섭게 보이는 것"과 "실제로 무서운 것"이 다르다는 걸 보여 준다.

### 6.6 쫓아오는 것들

| 에피소드 | 쫓아오는 것 | 왜 쫓아오나 | 솜이 빠져나가는 방법 |
|---|---|---|---|
| 튜토리얼 | 무너져 내리는 흙더미 | 폭풍에 젖은 비탈이 또 무너진다 | 끝까지 달려 평지로 |
| 1 | **멧돼지** | 진흙을 파헤치다 솜에게 놀라 들이받으며 돌진 | 쓰러진 나무 밑 좁은 틈으로 쏙. 멧돼지는 나무에 부딪혀 씩씩대다 돌아감 |
| 2 | **불어난 물살** | 상류에 쌓였던 나뭇가지 더미가 터져 흙탕물이 다시 밀려옴. 먹을 데려간 바로 그 물 | 높은 바위 위로 기어오름. 물이 발밑으로 지나감 |
| 3 | **농장 개** | 밤에 마당에 들어온 솜을 보고 낡은 사슬을 끊음 | 울타리 밑 좁은 틈을 지나 배수관 입구로. 개는 머리가 안 들어가 짖기만 함 |
| 4 | **족제비** | 배수로에 사는 사냥꾼. 좁은 관을 솜보다 잘 다님 | 굴 출구의 물웅덩이를 크게 뛰어 건넘. 족제비는 물가에서 멈춤 |
| 5 | **여우** (찢어진 귀) | 농장에서부터 솜의 냄새를 따라왔다. 그저 배가 고프다 | 고라니가 갈대를 헤치고 뛰어나와 여우가 놀란 틈에, 갈대 속에 얼어붙어 숨음 |
| 6 | **여우** (최종) | 눈밭에서 두 토끼를 발견 | 가시 돋친 찔레 덤불 속으로. 여우는 가시 때문에 들어오지 못한다 |

- 여우는 **한쪽 귀가 찢어진** 깡마른 여우다. Ep3 도착 장면 배경에 실루엣으로 처음 비치고(솜은 모름), Ep5 고라니의 경고, Ep5·Ep6 추격으로 이어지는 유일한 반복 추격자다.
- 엔딩 크레딧의 마지막 후일담 일러스트에서, 봄을 맞은 여우가 굴 앞에서 새끼들을 돌보는 모습을 보여 준다. 여우도 가족을 먹여 살리려 애쓰는 동물일 뿐이다 ([10.3](#103-엔딩-크레딧과-후일담-일러스트)).
- 다른 쫓아오던 동물과 방해하던 동물(멧돼지, 농장 개, 족제비, 까마귀, 왜가리, 수탉·거위, 매)도 크레딧에서 후일담을 보여 준다.

## 7. 프롤로그 (오프닝 영상)

- 형식: 인게임 도트로 만든 장면. **대사와 자막 없음.** 음악, 효과음, 몸짓만으로 전달. 약 2분.
- 아무 키나 **길게** 누르면 스킵.
- 음악: 메인 테마 '온기' 오르골 버전 → 폭풍에서 끊김 → 빗소리와 물소리 → 마지막에 오르골 한 소절.

| # | 장면 | 화면 | 소리 |
|---|---|---|---|
| 1 | 산자락 | 늦가을. 시냇물이 흐르는 비탈 위, 참나무 뿌리 사이에 작은 굴 | 새소리, 시냇물 |
| 2 | 굴 앞 | 먹이 먼저 고개를 내밀고 코를 씰룩이며 주위를 살핀 뒤 나온다. 솜은 먹의 등 뒤에 바짝 붙어 조심조심 나온다 (접힌 귀) | 오르골 테마 시작 |
| 3 | 풀밭 | 둘이 풀을 뜯는다. 먹이 네잎클로버를 찾아 솜 앞에 내려놓는다. 솜이 냄새를 맡더니 그냥 먹어 버린다. 먹이 잠깐 멍하다가, 둘이 코를 맞댄다 | 오르골 |
| 4 | 숨바꼭질 | 먹이 덤불 뒤로 숨는다. 솜이 두리번거리다 귀를 늘어뜨린다. 덤불 뒤에서 **쿵·쿵·쿵**. 솜의 귀가 쫑긋 서고, 소리 나는 쪽으로 깡충깡충 가서 먹을 찾아낸다. 둘이 빙키 | 발 구르기 3번 (또렷하게) |

## 8. 튜토리얼 '비 그친 아침'

- **장소**: 무너진 비탈 아래 → 폭풍이 할퀴고 간 숲 → 시냇물이 강과 만나는 곳.
- **음악 없음**: 물방울, 젖은 낙엽 밟는 소리, 솜의 숨소리만. 혼자가 된 외로움을 강조하고, Ep1에서 첫 노래가 시작될 때의 해방감을 크게 만든다.
- **길이**: 약 2분. 동작마다 1번씩만 짚고 짧게 끝낸다.

### 8.1 시작

프롤로그 마지막 장면에서 그대로 이어진다. 솜이 시작 지점에 서 있고, 대기 상태와 같이 몸을 털어 진흙을 떨어내거나 두리번거린다. "아무 키나 눌러 출발" 안내가 뜨고, 키를 누르면 카운트인 없이 바로 달려 나간다.

### 8.2 정지 안내 방식

1. 입력해야 할 순간 직전에 게임이 0.3초에 걸쳐 느려지다 **멈춘다**.
2. 화면이 살짝 어두워지고 장애물이 강조되며, 키 아이콘과 안내 문구가 뜬다.
3. 올바른 키를 누르면 즉시 재개되며 솜이 그 동작을 해서 장애물을 피한다.
4. 틀린 키를 누르면 아이콘이 흔들리고 계속 기다린다.
5. 튜토리얼에는 실패가 없다. 부딪혀도 온기가 줄지 않는다.

### 8.3 단계

안내 문구는 조작 안내(UI)일 뿐이고, 솜은 끝까지 말하지 않는다.

| 단계 | 상황 | 안내 문구 | 배우는 것 |
|---|---|---|---|
| 0 | 솜이 무너진 비탈 아래 서 있음 | "아무 키나 눌러 출발" | 자동 달리기 |
| 1 | 쓰러진 나뭇가지 | "[Space] 점프" | 점프 |
| 2 | 큰 돌 | 1차 정지 "[Space] 점프" → 정점에서 2차 정지 "공중에서 한 번 더!" | 이중점프 |
| 3 | 낮게 걸린 부러진 가지 (긴 것) | "[S] 누르고 있기" + 남은 길이 표시 막대 | 숙이기 |
| 4 | 나무에서 떨어지는 솔방울 | "[S] 짧게 — 구르는 동안엔 다치지 않아요" | 구르기, 무적 |
| 5 | 넓은 물웅덩이 | 1차 "[Space] 점프" → 2차 "[Shift] 대쉬" | 점프 + 대쉬 |
| 6 | 길을 막은 마른 덤불 | "[Shift] 대쉬로 뚫고 지나가기" | 대쉬 돌파 |
| 7 | 비탈 아래로 뚝 떨어지는 지형 | "땅에 닿기 직전 [S] — 착지 구르기" | 착지 구르기 (놓쳐도 진행) |
| 8 | 젖은 클로버 | "풀잎을 먹으면 몸이 따뜻해져요" + 온기 게이지 표시 | 온기 게이지, 수집 |
| 9 | 까마귀 | 까마귀가 "까악, 까악" 울고 급강하하는 순간 정지 → "동물은 덮치기 전에 신호를 보내요. 듣고 피하세요" → 구르기 | 예고 → 실행 규칙 |
| 10 | 뒤쪽 비탈이 다시 무너져 흙더미가 쏟아져 내려옴 | "뒤에서 쫓아올 땐 멈추지 마세요. 실수하면 거리가 좁혀져요" + 거리 게이지. 짧은 점프 몇 번 후 흙더미가 평지에서 멈춤 | 추격 구간 |
| 11 | 시냇물이 강과 만나는 곳. 솜이 멈춤. 물가 나뭇가지에 걸린 검은 털 몇 가닥 | (안내 없음) 솜이 다가가 냄새를 맡는다. 코가 빠르게 씰룩이고 귀가 쫑긋 선다. 솜이 하류를 바라본다 | - |
| 12 | 마무리 | "이제부터는 음악에 맞춰 길이 열립니다. 귀를 기울이세요." → 에피소드 1 제목 카드 | 리듬 예고 |

## 9. 에피소드 상세

> - 구간표의 마디 수는 목표치. 곡이 나온 뒤 곡 구조에 맞춰 조정한다. 임시 박자 음원도 이 표대로 만들어져 있다 ([14.5](#145-임시-박자-음원)).
> - 에피소드 1~5는 [2.2](#22-에피소드-한-판의-구성)의 흐름(등장 → 만남 → 대기 → 카운트인 → 전반곡 → 중간 장면 → 추격 카운트인 → 후반곡 → 도착 장면)을 따른다.
> - 대화 속 솜의 반응은 괄호 안에 몸짓으로 적었다.

### 에피소드 1. 쓰러진 숲

| 항목 | 내용 |
|---|---|
| 장소 | 폭풍이 지나간 숲. 쓰러진 나무, 진흙, 물웅덩이, 시냇물 옆길 |
| 계절·시간 | 늦가을, 폭풍 다음 날 오전 |
| 전반곡 | '쓰러진 숲' — 어쿠스틱 기타·리코더·가벼운 퍼커션의 포크. 불안하지만 앞으로 나아가는 느낌. 메인 테마가 리코더로. 104 BPM, 52마디, 2분 |
| 후반곡 | '엄니' — 같은 악기에 묵직한 톰과 베이스. 멧돼지 발굽이 킥 드럼. 112 BPM, 40마디, 1분 26초 |
| 대기 소리 | 나뭇잎에서 떨어지는 물방울, 새소리, 불어난 시냇물 |
| 새 기믹 | 휘어진 어린나무, 걸쳐진 나무, 진흙 웅덩이 |
| 방해하는 동물 | 까마귀 |
| 쫓아오는 것 | 멧돼지 |
| 만나는 동물 | 청설모 |

**등장**

솜이 진흙 묻은 몸으로 천천히 걸어 들어와 멈춘다. 머리 위 나뭇가지에서 청설모가 쪼르르 내려온다. 솜은 깜짝 놀라 얼어붙는다.

> 청설모: "어, 너 저 위 비탈 굴에 살던 하얀 꼬마지? 어젯밤 비탈 무너지는 소리 엄청났어!"
>
> (솜이 귀를 늘어뜨린다. 그리고 뒤를 돌아 먹이 없는 옆자리를 본다.)
>
> 청설모: "까만 애? 가슴에 흰 점 있는? 봤어 봤어! 새벽에 나뭇가지에 매달려서 물길 따라 떠내려가더라. 저 아래쪽으로."
>
> (솜의 귀가 번쩍 선다. 하류 쪽을 본다.)
>
> 청설모: "근데 그쪽 숲엔 지금 멧돼지가 진흙 파헤치고 다녀. 걔들은 앞에 뭐가 있든 그냥 들이받는다? 조심해!"

청설모가 나무 위로 사라진다. 대기 상태로 넘어간다.

**스테이지 중 사건**

- 전반곡: 폭풍이 할퀸 숲. 쓰러진 나무와 진흙 사이를 달린다. 배경에서 다람쥐와 작은 새들이 흩어진 둥지를 고치고 있다. 곡 후반에는 까마귀들이 젖은 땅에서 먹이를 찾다가 솜에게 달려든다.
- 중간 장면: 음악이 잦아들고 솜이 멈춘다. 앞쪽 진흙탕에서 꿀꿀, 쿵쿵 하는 소리. 거대한 등과 엄니가 진흙 위로 솟는다. 멧돼지가 고개를 들고, 솜과 눈이 마주친다. 솜이 얼어붙는다.
- 추격 카운트인: 멧돼지가 앞발로 땅을 긁는다. 긁, 긁, 긁, **푸흥!**
- 후반곡 (추격): 놀란 멧돼지가 솜을 향해 돌진한다. 지나가는 길의 어린나무가 부러지고 덤불이 날아간다. 화면에는 멧돼지의 주둥이와 엄니, 앞다리만 크게 보인다.
- 탈출: 쓰러진 큰 나무 밑의 좁은 틈. 솜이 숙여서 쏙 빠져나간다. 뒤따르던 멧돼지는 나무에 쿵 부딪혀 씩씩대다가, 흥미를 잃고 진흙탕으로 돌아간다.

**도착 장면** (대사 없음)

숲이 끝나고 시냇물이 넓은 강과 만나는 곳. 솜이 숨을 헐떡이며 멈춘다. 흙탕물 강물이 거세게 흐른다. 물가에 걸린 나뭇가지에서 검은 털 한 가닥이 바람에 흔들린다. 솜이 그것을 한참 바라보다가, 강을 따라 하류 쪽으로 몸을 돌린다.

### 에피소드 2. 불어난 강

| 항목 | 내용 |
|---|---|
| 장소 | 폭풍으로 불어난 흙탕물 강. 무너지는 강둑, 떠내려오는 나뭇가지, 징검돌, 끊어진 나무다리 |
| 계절·시간 | 늦가을, 흐린 오후 → 저녁 |
| 전반곡 | '흙탕물' — 피아노·현악 + 물방울 같은 마림바 아르페지오. 벌스 2에 셋잇단 리듬. 116 BPM, 56마디, 1분 56초 |
| 후반곡 | '물의 벽' — 현악 트레몰로와 팀파니. 밀려오는 물처럼 쉬지 않는 리듬. 124 BPM, 40마디, 1분 17초 |
| 대기 소리 | 거센 물살, 오리 울음, 바람 |
| 새 기믹 | 무너지는 강둑, 떠내려오는 나뭇가지(셋잇단), 징검돌 |
| 방해하는 동물 | 왜가리 |
| 쫓아오는 것 | 불어난 물살 |
| 만나는 동물 | 청둥오리 엄마와 새끼 오리들 |

**등장**

솜이 강둑에 걸어 들어와 멈춘다. 거센 흙탕물을 보자 귀가 등에 붙고 몸이 떨린다. 먹을 데려간 물이다. 물가 수풀에서 청둥오리 엄마가 새끼 오리 셋을 데리고 나온다.

> 청둥오리: "어머, 꼬마야, 거기 너무 가까이 가면 안 돼. 물이 아직 성나 있단다."
>
> 청둥오리: "까만 토끼? …아, 어제 아침에 봤어! 나뭇가지 위에 납작 엎드려서 떠내려가더구나. 귀를 이렇게 쫑긋 세우고 있었으니까, 살아 있었을 거야."
>
> (솜이 뒷발로 서서 하류를 멀리 본다. 코가 빠르게 씰룩인다.)
>
> 청둥오리: "이 강은 저 아래 농장 옆을 지나가. 강둑을 따라가면 돼. 강둑이 자꾸 무너지니까 발밑 조심하고. 얘들아, 길 좀 알려 드리렴."

새끼 오리들이 "삐약" 하며 물가로 앞장선다. 대기 상태로 넘어간다.

**스테이지 중 사건**

- 전반곡: 무너지는 강둑 위를 달린다. 밟은 흙이 뒤에서 물로 무너져 내린다. 얕은 물에 꼿꼿이 서 있던 왜가리가 목을 S자로 접더니 부리로 내리찍는다. 토끼의 눈에는 하늘까지 닿는 창 같다.
- 전반곡 벌스 2: **떠내려오는 나뭇가지 구간.** 음악이 셋잇단 리듬으로 바뀐다. 새끼 오리들이 앞서 헤엄치며 밟을 나뭇가지 근처에서 "삐약" 하고 울어 착지 지점을 알려 준다.
- 중간 장면: 음악이 잦아들고 솜이 멈춘다. 상류에서 우르릉 소리. 오리 엄마가 새끼들을 불러 수풀로 숨는다. 강물이 갑자기 탁해지고 수위가 오른다. 상류에 쌓인 나뭇가지 더미가 삐걱인다.
- 추격 카운트인: 우르릉, 우르릉, 우르릉, **콰앙!** 나뭇가지 더미가 터진다.
- 후반곡 (추격): 흙탕물이 통나무와 함께 밀려온다. 프롤로그에서 먹을 데려간 바로 그 물이다. 화면 왼쪽에서 물의 벽과 굴러오는 통나무가 쫓아온다.
- 탈출: 강가의 높은 바위를 연속 점프로 기어오른다. 물이 발밑으로 지나간다.

**도착 장면** (대사 없음)

저녁. 바위 위에서 솜이 흠뻑 젖은 몸을 부르르 턴다. 날이 추워진다. 솜이 몸을 동그랗게 말고, 습관처럼 옆으로 몸을 기댄다. 옆자리는 비어 있다. 솜의 귀가 천천히 늘어진다. 멀리 하류 쪽에 농장의 불빛이 반짝인다.

**등장**

솜이 키 큰 갈대 사이로 걸어 들어와 멈춘다. 갈대가 크게 흔들리더니, 거대한 얼굴이 불쑥 나타난다. 길게 뻗은 두 개의 송곳니. 솜은 그 자리에 얼어붙는다.

> 고라니: "…놀랐니? 미안. 이 이빨 때문에 다들 도망가더라. 나는 풀만 먹어."

(고라니가 천천히 고개를 숙여 솜과 눈높이를 맞춘다. 조명이 부드러워진다.)

> 고라니: "다리 저는 까만 토끼? …응. 갈대밭 너머 들판, 늙은 버드나무 쪽으로 절뚝절뚝 가는 걸 봤어. 며칠 전에."
>
> (솜이 뒷발로 서서 갈대 너머를 보려 하지만, 갈대가 너무 높다.)
>
> 고라니: "그런데 너, 뒤에 냄새가 따라오고 있어. 귀 찢어진 여우야. 어젯밤부터 네 발자국을 맡고 다니더라."
>
> (솜의 귀가 등에 붙는다. 뒤를 돌아본다. 갈대만 흔들린다.)
>
> 고라니: "멈추지 말고 가. …나도 근처에 있을게."

고라니가 갈대 속으로 사라진다. 대기 상태로 넘어간다.

**스테이지 중 사건**

- 전반곡: 바람이 갈대를 꺾어 넘기고 마른 덤불을 굴려 보낸다. 살얼음 낀 웅덩이 위를 미끄러지듯 지난다. 곡 후반에는 철새 떼가 갈대밭에서 한꺼번에 날아오르고, 하늘에서 매가 내리꽂힌다.
- 해가 기울수록 **추위**가 시작된다. 온기가 천천히 줄어, 서리 맞은 풀을 계속 먹어야 한다.
- 전반곡 엔딩 (7/8): 바람이 멎는다. 불안하게 절뚝이는 변박. 장애물이 드문드문 나온다. 마지막 박에 솜이 멈춘다.
- 중간 장면: 갑자기 조용하다. 뒤쪽 갈대가 한 줄로 흔들리며 다가온다. 갈대 사이로 찢어진 귀가 보인다.
- 추격 카운트인: 사각, 사각, 사각. 그리고 여우가 갈대 위로 **높이 뛰어오른다.**
- 후반곡 (추격): 여우가 갈대를 헤치며 쫓아온다. 여우는 쥐를 잡을 때처럼 높이 뛰어올라 위에서 덮친다. 화면에는 여우의 그림자와 번쩍이는 눈, 높이 솟는 몸이 보인다.
- 탈출: 여우가 마지막으로 높이 뛰어오르는 순간, 옆 갈대를 헤치고 고라니가 뛰쳐나온다. 커다란 몸에 놀란 여우가 공중에서 몸을 틀어 물러난다. 그 틈에 솜은 갈대 밑동 사이에 몸을 납작 붙이고 얼어붙는다. 여우는 한참 코를 킁킁대다가 냄새를 놓치고 멀어진다.

**도착 장면** (대사 없음)

해 질 녘. 갈대밭이 끝나고 넓은 들판이 보인다. 들판 저 끝에 늙은 버드나무 한 그루. 하늘에서 하얀 것이 하나 내려와 솜의 코끝에 앉는다. 솜이 재채기를 한다. 첫눈이다.

밤. 솜은 갈대 밑동 사이에서 혼자 몸을 동그랗게 만다. 온기 게이지 마지막 한 칸이 깜박인다. 몸이 떨린다. 화면이 하얘지며 회상이 시작된다.

> **회상 '처음 만난 날'** — 눈 오는 밤, 더 작은 아기 솜이 눈밭에 홀로 떨고 있다. 검은 아기 토끼가 다가와 냄새를 맡더니, 말없이 옆에 붙어 웅크린다. 아기 솜의 떨림이 조금씩 멎는다.

현재. 솜이 눈을 뜬다. 밤사이 눈이 소복이 쌓였다. 솜이 몸을 부르르 털어 눈을 떨어내고, 들판 쪽을 바라본다.

### 에피소드 6. 첫눈 (최종)

마지막 에피소드는 전반·후반으로 나누지 않고 **이어진 긴 1곡 '함께'**로 진행한다. 곡이 한 번도 끊기지 않은 채 1부(혼자 달리기) → 2부(재회 장면) → 3부(함께 달리기)로 흐른다. 그래서 중간 장면과 추격 카운트인이 없다. 도와주는 동물은 나오지 않는다. 두 토끼만의 장면으로 남긴다.

| 항목 | 내용 |
|---|---|
| 장소 | 첫눈 덮인 들판 → 늙은 버드나무 → 개울가의 찔레 덤불 |
| 계절·시간 | 첫눈 다음 날, 이른 아침 → 낮 |
| 곡 | '함께' — 지금까지 모든 곡의 모티프 + 메인 테마 대편성. 138 → 152 BPM, 172마디, 약 4분 44초 |
| 1부 '하얀 들판' | 1–52마디, 138 BPM. 앰비언트 + 오케스트라. 혼자 달리는 눈밭 |
| 2부 '버드나무 아래' | 53–76마디, 138 BPM. 오르골 메인 테마. 재회 장면 (조작 없음) |
| 3부 '함께' | 77–172마디, 152 BPM. 대편성. 중간에 하프타임으로 바뀌며 메인 테마를 두 악기가 **돌림노래(캐논)**로 연주 |
| 대기 소리 | 거의 무음. 눈 내리는 사각거림, 아주 먼 까마귀 소리 |
| 새 기믹 | 눈더미, 떨어지는 눈, 눈 덮인 구덩이, 찔레 가시, 함께 달리기 |
| 방해하는 동물 | 까마귀 |
| 쫓아오는 것 | 여우 (최종) |

**등장**

온통 하얀 들판. 솜이 눈을 헤치며 천천히 걸어 들어와 멈춘다. 흰 눈 위에서 흰 솜은 거의 보이지 않는다. 대기 중 솜은 귀에 쌓이는 눈을 털어 내고, 뒷발로 서서 들판을 바라본다.

**카운트인**

솜이 뒷발로 구른다. 쿵, 쿵, 쿵. 그리고 4박째.

…아주 멀리서, 희미하게 **쿵.**

솜의 귀가 번쩍 선다. 그 순간 음악이 시작된다. 게임 내내 비어 있던 4박째가 처음으로 채워진다.

#### 1부 '하얀 들판' (138 BPM)

- 눈 덮인 들판과 눈 쌓인 덤불 사이를 달린다. 나뭇가지에서 눈이 떨어지고, 눈 밑에 구덩이가 숨어 있다.
- 추위 때문에 온기가 계속 줄어든다. 눈 속에서 풀싹을 파먹으며 달린다.
- 곡이 진행될수록 멀리 있던 버드나무가 조금씩 가까워진다.
- 마지막: 음악이 잦아든다. 버드나무 아래, 하얀 눈 위에 작고 **까만 점** 하나. 음악은 멈추지 않고 2부로 넘어간다.

#### 2부 '버드나무 아래' — 재회 장면 (138 BPM, 조작 없음)

곡은 계속 흐른다. 음악이 오르골 메인 테마로 바뀌고, 그 박자에 맞춰 장면이 흘러간다. HUD가 사라지고 입력을 받지 않는다. 대사 없음.

| # | 마디 | 장면 |
|---|---|---|
| 1 | 53–54 | 솜이 멈춘다. 귀가 선다. 까만 점이 움직인다. 고개를 든다 |
| 2 | 55–56 | 솜이 달려간다. 몇 걸음 앞에서 속도를 늦추고, 코를 씰룩이며 천천히 다가간다 |
| 3 | 57–58 | 버드나무 뿌리 밑 얕은 구멍 앞의 먹. 몸이 마르고 털이 엉켜 있다. 한쪽 뒷다리를 들고 있다. 주위에 갉아 먹은 나무껍질 조각들 |
| 4 | 59–60 | 먹이 일어나려다 비틀거린다 |
| 5 | 61–64 | 둘이 코를 맞댄다. 오래 |
| 6 | 65–68 | 솜이 먹의 귀를 핥아 준다. 프롤로그에서 먹이 해 주던 것처럼. 먹이 솜에게 몸을 기댄다 |
| 7 | 69–70 | 솜이 작게 빙키를 한다. 그리고 먹 옆에 바짝 붙어 엎드린다. 둘 위로 눈이 내린다 |
| 8 | 71–72 | 오르골 위로 낮은 현악의 여우 동기가 스민다. 솜의 귀가 한쪽으로 돌아간다. 들판 너머 언덕 위에 찢어진 귀의 여우. 흰 눈 위에서 검은 먹은 너무 잘 보인다 |
| 9 | 73 (1박) | 솜이 **쿵!** 세게 구른다 (프롤로그 5번 장면의 경고와 같다). 먹이 고개를 든다. 여우가 언덕을 내려오기 시작한다 |
| 10 | 73–76 | 버드나무 구멍은 너무 얕다. 솜이 개울가 쪽, 가시 돋친 찔레 덤불을 본다. 음악이 차오르고, 76마디 끝에서 둘이 달리기 시작한다 |

- 장면은 컷신 시간표가 아니라 **박자 이벤트**로 구동한다. 곡과 장면이 어긋나지 않는다.
- 3부에서 실패해도 2부는 다시 보여 주지 않는다. 3부 체크포인트에서 다시 시작한다.

#### 3부 '함께' (152 BPM)

- 77–80마디는 장애물이 없다. 둘이 달리기 시작하고, 플레이어가 새 템포에 몸을 맞추는 구간이다 (카운트인 역할).
- 여우가 눈밭을 가로질러 쫓아온다.
- **함께 달리기**: 다리를 저는 먹이 솜의 1박 뒤에서 달리며 솜의 동작을 그대로 따라 한다 (먹은 같은 장애물에 1박 늦게 도착하므로 자연스럽게 메아리가 된다). 솜이 완벽을 내면 먹도 잘 넘고, 솜이 부딪히면 먹도 휘청인다. 음악에서도 솜의 동작 소리를 먹의 동작 소리가 1박 뒤에 따라 한다.
- 3부에서는 **추위로 온기가 줄지 않는다.** 둘이 함께이기 때문이다.
- 중반: 먹이 점점 뒤처진다. **하프타임 구간** — 솜이 속도를 늦춰 먹과 나란히 달린다 (그래서 음악이 하프타임으로 바뀐다). 여우는 눈 언덕 뒤로 돌아가 잠시 보이지 않는다. 장애물 밀도를 낮추고, 메인 테마가 돌림노래로 흐른다. 개울가의 찔레 덤불이 보인다.
- 아웃트로: 언덕 뒤에서 여우가 다시 뛰쳐나온다. 템포가 돌아온다. 마지막 이중점프 + 대쉬로 둘이 찔레 덤불 속으로 뛰어든다. 뛰어드는 순간 곡이 끝난다.

## 10. 엔딩과 에필로그

엔딩 영상과 에필로그는 대사와 자막 없음. 흐름: 엔딩 영상 '찔레 덤불' → 에필로그 '봄' → 엔딩 크레딧 (후일담 일러스트).

### 10.1 엔딩 영상 '찔레 덤불'

| # | 장면 | 소리 |
|---|---|---|
| 1 | 찔레 덤불 깊은 곳. 두 토끼가 서로에게 바짝 붙어 떨고 있다 | 거친 숨소리 |
| 2 | 덤불 틈으로 여우의 주둥이가 들어온다. 가시에 코가 찔린 여우가 깨갱 하며 물러난다 | 여우 울음 |
| 3 | 여우가 덤불 주위를 빙빙 돈다. 다른 틈으로 앞발을 넣어 보지만 가시뿐이다 | 바스락 |
| 4 | 여우가 앉아서 덤불을 한참 바라본다. 눈이 내린다 | 정적 |
| 5 | 여우가 일어나 돌아선다. 눈밭 위로 발자국을 남기며 멀어진다 | 멀어지는 발소리 |
| 6 | 덤불 안. 두 토끼의 떨림이 천천히 멎는다. 솜이 먹의 귀를 핥는다. 먹이 옆으로 털썩 눕는다 (안심). 솜이 그 옆에 몸을 붙인다 | 오르골 테마 |
| 7 | 밤. 눈 덮인 찔레 덤불을 멀리서. 덤불 안쪽에서 아주 작게, 두 개의 숨결이 하얗게 피어오른다 | 메인 테마 풀편성 |

### 10.2 에필로그 '봄'

| # | 장면 |
|---|---|
| 1 | 겨울. 찔레 덤불 밑에 새 굴이 생겼다. 눈 오는 밤, 굴 안에서 둘이 몸을 맞대고 웅크린다. **프롤로그 6번 장면과 같은 구도.** 이번엔 먹이 아니라 솜이 먹의 귀를 핥아 준다 |
| 2 | 눈이 녹는다. 들판에 첫 풀이 돋는다 |
| 3 | 먹이 굴에서 나온다. 다리를 절지 않는다. 솜이 먹의 뒤가 아니라 **옆**에서 함께 나온다 |
| 4 | 풀밭. 솜이 네잎클로버를 찾아 먹 앞에 내려놓는다. 먹이 냄새를 맡더니 그냥 먹어 버린다. 솜이 잠깐 멍하다가, 둘이 코를 맞댄다 (프롤로그 3번 장면을 뒤집은 장면) |
| 5 | 숨바꼭질. 먹이 덤불 뒤로 숨는다. 솜이 두리번거린다. 덤불 뒤에서 **쿵·쿵·쿵.** 솜이 소리를 따라가 먹을 찾아낸다. 둘이 나란히 빙키 |

마지막 빙키에서 화면이 멈추고 천천히 어두워지면, 그대로 엔딩 크레딧 곡이 시작된다.

### 10.3 엔딩 크레딧과 후일담 일러스트

에필로그가 끝나면 크레딧 곡과 함께 화면이 둘로 나뉜다. **오른쪽에는 크레딧이 위로 올라가고, 왼쪽에는 후일담 일러스트**가 한 장씩 바뀐다.

일러스트는 여정에서 만난 동물들의 그해 봄 모습이다. 솜을 도와준 동물뿐 아니라, **괴물처럼 쫓아오고 덮치던 동물들**도 나온다. 토끼의 눈에 괴물 같던 동물들도 저마다 돌볼 가족과 하루하루가 있는 평범한 동물이었다는 것을 보여 준다. 따로 있던 쿠키 영상은 이 크레딧에 합친다.

**화면 구성** (480×270 기준)

| 영역 | 위치·크기 | 내용 |
|---|---|---|
| 왼쪽 | x 16~304, 세로 가운데. 288×216 (4:3) | 후일담 일러스트. 얇은 액자 테두리 |
| 오른쪽 | x 320~464 (폭 144) | 크레딧 글자. 곡이 끝날 때 마지막 줄이 화면 가운데에 오도록 일정한 속도로 위로 올라감 |
| 배경 | 전체 | 짙은 남색. 아주 작은 꽃잎이 가끔 떨어짐 |

- 일러스트는 인게임보다 큰 한 장짜리 도트 그림이다. 2~4프레임의 작은 움직임(눈 깜박임, 꼬리, 숨결, 흔들리는 풀)을 넣어 살아 있는 그림처럼 보이게 한다.
- 일러스트에는 글자를 넣지 않는다 (대사·자막 없음 원칙).
- 일러스트는 곡 박자에 맞춰 **4마디마다** 크로스페이드로 바뀐다. 마지막 여우만 8마디.
- 순서는 여정 순서를 따른다. 한 에피소드 안에서는 도와준 동물 → 쫓아오던 동물 순.
- 크레딧 곡: '온기' 크레딧 편곡 (오르골 → 피아노 → 현악 풀편성). 84 BPM, 60마디, 약 2분 51초.
- 아무 키를 길게 누르면 마지막 여우 일러스트로 건너뛴다.
- 클리어 후 갤러리에서 일러스트를 한 장씩 다시 볼 수 있다.

### 11.2 토끼의 눈높이 연출

평범한 동물을 괴물처럼 보이게 하는 방법. 해부학은 실제 동물을 따르고, **보여 주는 방식**으로 무섭게 만든다.

- **카메라는 토끼 눈높이.** 지면 가까이에 두어 모든 것이 올려다보이게 한다.
- **다 보여 주지 않는다.** 큰 동물은 발, 주둥이, 이빨, 그림자, 눈빛만 화면에 들어오게 해 크기를 상상하게 한다.
- **역광과 그림자.** 위협적인 순간에는 동물을 실루엣으로, 눈에만 빛이 반사되게 한다.
- **소리.** 거친 숨소리, 발이 땅을 울리는 진동을 크게.
- **같은 동물, 다른 조명.** 도와주는 동물(늙은 고양이, 고라니)은 처음에 위협과 같은 연출로 등장했다가, 말을 시작하면 조명이 밝아지고 실루엣이 둥글어진다.

### 11.5 가독성 — 흰 눈 위의 흰토끼

Ep6 눈밭에서 흰 캐릭터가 흰 배경에 묻히는 문제.

- 솜에게 짙은 남색 1px 외곽선.
- 배경의 눈은 푸른 기가 도는 회백색으로, 솜의 따뜻한 흰색과 명도·채도를 분리한다.
- 솜의 입김과 발밑에 튀는 눈가루가 위치를 보조한다.
- Ep6 등장 장면에서는 일부러 솜이 눈에 묻혀 잘 안 보이게 연출하고(회상 '작년 첫눈'과 연결), 달리기 시작하면 외곽선을 켜서 플레이에는 지장이 없게 한다.

### 11.6 음악 연동 연출

배경 요소가 박자에 맞춰 움직인다. 나뭇잎의 물방울(Ep1), 강물의 물결과 떠내려오는 나뭇가지(Ep2), 길어지는 그림자와 꺼지는 창문 불(Ep3), 배수구 틈의 차 불빛(Ep4), 바람에 쓸리는 갈대(Ep5), 떨어지는 눈(Ep6). 큰 동물의 발걸음은 킥 드럼과 화면 흔들림을 맞춘다.

- 카운트인: 솜의 발 구르기 3번 + 빈 1박. Ep6에서만 빈 박에 먹의 희미한 발 구르기가 들어간다.

- 동물의 예고음: 실제 울음소리를 녹음·가공해 그 곡의 박자와 음계에 맞춘다.
- 풀잎 먹는 소리: 곡의 음계에 맞춘 짧은 차임 + 오물오물.
- 대기 소리: 에피소드별 자연 소리. 솜의 귀 돌리기 애니메이션과 소리 방향을 맞춘다.
- 레이어 음악: 곡을 여러 스템(반주, 코러스, 화음 등)으로 나눠 동시에 재생하고, 콤보에 따라 스템 볼륨을 올린다.

## 14. 개발 참고 (Godot)

현재 프로젝트 설정 (Godot 4.7, 480×270, canvas_items 스트레치, 픽셀 필터 Nearest)이 이 기획에 그대로 맞는다.

### 14.1 스테이지 상태

한 스테이지는 다음 상태를 차례로 지난다.

```
Ep1~5: INTRO_WALK → DIALOGUE(있을 때) → IDLE → COUNT_IN → PLAYING(전반곡)
       → MID_SCENE → CHASE_COUNT_IN → PLAYING(후반곡) → OUTRO → RESULT
Ep6:   INTRO_WALK → IDLE → COUNT_IN → PLAYING(긴 1곡, 2부는 곡 안의 장면) → OUTRO → RESULT
```

- `INTRO_WALK`: 솜이 정해진 위치까지 천천히 걸어옴. 입력 무시.
- `DIALOGUE`: 대화창. 확인 키로 넘김. 끝나면 1초 입력 무시.
- `IDLE`: 대기 소리 재생, 대기 행동 무작위 재생, 아무 키 입력 대기. 30초 무입력 시 졸기.
- `COUNT_IN`: 곡의 BPM으로 1마디. 1~3박에 발 구르기, 4박은 비움 (Ep6만 먹의 소리).
- `PLAYING`: 곡 재생, 음악 시간 기준으로 진행. 곡이 끝나면 다음 상태로.
- `MID_SCENE`: 전반곡이 끝난 뒤, 쫓아오는 것이 나타나는 장면. 입력 무시. 한 번 본 뒤에는 재시작 때 건너뜀.
- `CHASE_COUNT_IN`: 후반곡의 BPM으로 1마디. 1~3박 쫓아오는 것의 소리, 4박 가장 큰 소리.
- `OUTRO`: 도착 장면.
- `RESULT`: 전반·후반 합산 결과.
- Ep6 2부(재회 장면)는 별도 상태가 아니라 `PLAYING` 안에서 "조작 없는 구간"으로 처리한다. 입력을 막고 HUD를 숨기며, 장면은 박자 이벤트로 구동한다.

### 14.2 음악 시간

매 프레임 곡 시간을 이렇게 계산한다.

```gdscript
var t := music.get_playback_position() \
	+ AudioServer.get_time_since_last_mix() \
	- AudioServer.get_output_latency() \
	+ user_audio_offset
```

- 솜의 x는 `t`(템포 맵이 있으면 구간별로 환산한 박자)로 정한다. y는 `CharacterBody2D` 물리.
- 동물의 예고와 행동은 AnimationPlayer 시간이 아니라 **박자 이벤트**(곡 시간이 특정 박자를 넘는 순간)로 구동한다.
- 카운트인은 곡 재생 전이므로, 곡의 BPM으로 계산한 별도 타이머로 구동하고 4박 끝에 `play()`를 호출한다. 출력 지연만큼 미리 호출해 첫 박을 맞춘다.

### 14.3 레벨 제작

- 지형은 `TileMapLayer`, 장애물·동물은 씬 인스턴스.
- `@tool` 스크립트로 에디터 뷰에 **1박·1마디 격자선과 마디 번호**를 그린다.
- 장애물마다 `@export var beat: float` (목표 박자). 에디터에서 x 위치를 박자에 자동 스냅 (`x = beat × 박당 픽셀`), 판정 계산에도 같은 값을 쓴다.
- 템포 맵은 `Resource`로: `[시작 마디, BPM, 한 마디의 박 수]` 목록. 예) Ep5 전반곡 `[1, 140, 4], [53, 140, 3.5]`, Ep6 `[1, 138, 4], [77, 152, 4]`.
- 곡 데이터에는 **시작 오프셋**(곡 파일에서 1마디 1박이 시작되는 시간)도 둔다. 임시 음원은 0, 실제 곡에 앞 무음이 있으면 그 길이를 적는다.

### 14.4 그 밖

- 체크포인트 재시작: `play(from_position)`으로 곡 위치를 옮기고 레벨 상태를 되돌린다.
- 튜토리얼: 음악이 없으므로 내부 가상 시계를 쓰고, 정지 안내 때 시계를 멈춘다 (안내 UI는 `PROCESS_MODE_ALWAYS`).
- 레이어 음악: `AudioStreamSynchronized`로 스템을 동시 재생하고 콤보에 따라 각 스템 볼륨을 조절.
- 오디오 보정 화면: 박자 소리에 맞춰 키를 누르게 하고, 평균 오차를 `user_audio_offset`으로 저장.
- 입력 액션 추가 필요: `jump`(기존), `dash`, `crouch`(숙이기·구르기 겸용), `pause`, `ui_accept`(대화 넘기기). 기존 `move_left`·`move_right`는 자동 달리기에선 쓰지 않는다.
- 추락 복귀: 솜의 y가 구덩이 바닥 판정선 아래로 내려가면 `FALLEN` 상태(물보라, 온기 -1). x는 계속 음악을 따라가고, 현재 x에 지면이 생기면 그 가장자리에 매달려 기어오르는 애니메이션으로 지면 위에 올린 뒤 2박 무적.
- 엔딩 크레딧: 크레딧 곡의 박자 이벤트로 4마디마다 일러스트를 바꾸고, 크레딧 글자의 스크롤 속도는 `(글자 전체 높이) ÷ (곡 길이)`로 정해 곡이 끝날 때 마지막 줄이 가운데에 오게 한다.

### 14.5 임시 박자 음원

곡은 나중에 직접 작업해 넣는다. 그 전까지 개발과 레벨 제작에 쓰도록, 기획서의 곡 목록([12.2](#122-곡-목록))과 구간표 그대로 **박자만 있는 임시 음원**을 만들어 두었다.

- 생성 스크립트: `tools/make_temp_music.py` (Python 3 + numpy). 프로젝트 폴더에서 `python tools/make_temp_music.py` 로 실행하면 전부 다시 만든다.
- 곡 정보(BPM, 박자, 마디 수, 구간)는 스크립트 맨 위 `SONGS` 목록에 있다. 기획서의 구간표가 바뀌면 여기도 고치고 다시 실행한다.
- 형식: WAV, 22,050Hz, 16비트, 모노. 0초에 1마디 1박이 시작한다 (앞 무음 없음).

**곡 파일** (`assets/music/temp/`)

| 파일 | 곡 |
|---|---|
| `ep1_a.wav` ~ `ep5_a.wav` | 각 에피소드 전반곡 |
| `ep1_b.wav` ~ `ep5_b.wav` | 각 에피소드 후반곡 |
| `ep6.wav` | 에피소드 6 긴 1곡 (138 → 152 BPM) |
| `credits.wav` | 크레딧 곡 (84 BPM) |

**들리는 소리**

| 소리 | 언제 |
|---|---|
| 낮은 킥 + 높은 클릭 | 마디 첫 박 |
| 중간 클릭 | 나머지 박 |
| 작은 틱 | 8분음표 뒷박 (박 사이를 잴 때) |
| 크래시 | 구간이 시작되는 마디 첫 박 (구간표의 인트로·벌스·코러스…) |
| 끝음 (킥 + 크래시) | 마지막 마디 다음 박. 곡이 끝나는 순간 = 탈출 순간 |

- Ep5 전반곡의 7/8 마디는 8분음표를 2+2+3으로 묶어 1·3·5번째 8분음표에 클릭이 온다.
- Ep6의 2부(재회 장면)는 클릭만 작게, 3부의 하프타임 구간은 1·3박에만 클릭이 온다.

**카운트인 효과음** (`assets/sfx/temp/`)

| 파일 | 쓰임 |
|---|---|
| `thump.wav` | 솜의 발 구르기 (카운트인 1~3박) |
| `thump_far.wav` | 먹의 희미한 대답 (Ep6 카운트인 4박) |
| `chase_beat.wav` | 추격 카운트인 1~3박 |
| `chase_accent.wav` | 추격 카운트인 4박 |

## 15. 제작 순서

| 단계 | 목표 | 내용 |
|---|---|---|
| 1. 프로토타입 | 재미 검증 | 회색 박스 그래픽, 스테이지 상태 흐름(등장 → 대기 → 카운트인 → 전반 → 중간 장면 → 추격 카운트인 → 후반), 솜 동작 5종, 음악 동기화, 임시 음원 `ep1_a` / `ep1_b`, 추격 1회 |
| 2. 버티컬 슬라이스 | 완성품 품질의 한 판 | 튜토리얼 + Ep1 완성 (아트, 실제 곡 2곡, 청설모 대화, 멧돼지 추격, 도착 장면) + 프롤로그 간이 버전 |
| 3. 본 제작 | 콘텐츠 | Ep2~6, 재회 장면, 엔딩, 에필로그, 엔딩 크레딧과 후일담 일러스트 12장 |
| 4. 마무리 | 다듬기 | 난이도 조정, 접근성, 연습 모드, 갤러리, 랭크 |

> - 레벨은 곡에 맞춰 만들어진다. 실제 곡이 나오기 전에는 **임시 박자 음원**([14.5](#145-임시-박자-음원))으로 레벨을 만들고, 실제 곡이 나오면 같은 BPM·마디 구조로 교체한다.
> - 실제 곡이 구간표와 마디 수가 달라지면, 구간표 → `SONGS` → 레벨 순으로 맞춘다.
